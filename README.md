# Exercise 5 — Three charts

All three charts are on `index.html`:

- A bar chart compares average energy use for 55-inch TVs by screen type.
- A scatter plot and line show electricity prices by year.
- A donut chart shows the share of TV models in three size groups.

Each chart has its own JavaScript file in `js/`. The CSV files in `data/` contain practice values; replace them with your own exported data before presenting the results as real data.

Run this command in this folder, then visit `http://localhost:5500`:

```bash
python3 -m http.server 5500
```
